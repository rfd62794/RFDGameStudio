# Trinity Siege Mechanics

## Core Mechanics
- **Tower Defense**: Build and upgrade towers to defend against waves.
- **Wave Survival**: Survive increasingly difficult enemy waves.
- **Base Upgrades**: Improve base defenses and resources.
- **Boss Fights**: Defeat the final boss wave to win.

## Progression System
- **Tower Upgrades**: Unlock new tower types and abilities.
- **Resource Management**: Collect and spend resources to build defenses.

## Win/Loss Conditions
- **Win**: Defeat the final boss wave.
- **Loss**: Base destruction.
