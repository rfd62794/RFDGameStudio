# SVG Graphics Tool

## Purpose
Generate **scalable vector graphics (SVG)** for games and prototypes.

## Features
- **Dynamic SVG generation** (e.g., icons, UI elements).
- **Pixel-perfect rasterization** (PNG/JPG export).
- **Integration with Phaser/Lua** (export to game engines).

## Usage
```bash
python svg_generator.py --input design.json --output assets/
```
