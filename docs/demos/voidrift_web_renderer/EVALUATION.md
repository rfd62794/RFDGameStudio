## What the web code is
- A self-contained canvas idle-mining slice: 19 tracked files under `VD:web/`, 1,195 lines of source (10 `src` files 1,180 plus `vite.config.ts` 15), plus a committed `web/dist` bundle and a 1,002-line lockfile. `VD:web/package.json:6-10` has only `dev`, `build`, `preview`: no test script and no test file.
- Shape: pure state plus systems taking `(state, dt)` (`VD:web/src/main.ts:41-45` runs asteroids, drones, refinery, forge, drone build) and DOM/canvas code only in `main.ts`, `renderer.ts` (407), `hud.ts` (181) and `index.html` (187).
- Scope is an MVP subset: iron only (`VD:web/src/constants.ts:19` "no Tungsten/Nickel in MVP"); the native game has four ores (`VD:assets/balance.toml:11-16`), sectors, narrative and tutorial.

## Coupling to the Rust game
- Drone FSM matches by name: web `VD:web/src/types.ts:1` and Rust `VD:src/components/game_state.rs:143-147` both have Holding, Outbound, Mining, Returning, Unloading.
- Constants are hand-copied, with no generator: `VD:web/src/constants.ts:1` "Ported from assets/balance.toml and assets/visual.toml". Most agree (`SHIP_SPEED` 210 = `VD:assets/balance.toml:5`; refinery 10 and 4.0 = lines 12-13; `HULL_TIME` 5.0 = line 19). Drift already exists: `SPAWN_DIST_MAX` 400 (`constants.ts:33`) vs 380 (`balance.toml:69`); `MAX_ASTEROIDS` 3 (`constants.ts:31`) vs `max_per_field = 1` (`balance.toml:67`, a per-field limit); the comment at `VD:web/src/systems/production.ts:7` cites `auto_process.rs`, but the Rust file is `VD:src/economy/process.rs`.
- Save formats are unrelated. Web: localStorage key `voiddrift_save_v1` (`constants.ts:60`), version 1 (`save.ts:5`), 10 camelCase fields (`types.ts:57-69`), drones restored as a count only (`save.ts:49-54`). Rust: serde JSON `SaveData` with about 40 snake_case fields (`VD:src/systems/persistence/schema.rs:4-60`), `SAVE_VERSION = 7` (`VD:src/systems/persistence/save.rs:17`), written by `io.rs:49,84`. A shared format does not exist and nothing converts between them.
- Generated vs duplicated: only the constants (`balance.toml`, `visual.toml` colours at `constants.ts:42-57`) could be generated by a small script; the simulation rules (`process.rs`, `drone/fsm.rs`) and the save schema must be duplicated and hand-synced. Randomness is unseeded `Math.random` (`state.ts:18,19,40,41`), so the slice is not testable until seeded.

## TS-native port into ts/src/games: feasible, small, but redundant
- Pure parts move almost verbatim: constants 64, types 69, state 78, save 68, systems 233 = 512 lines. The renderer (407) becomes a React canvas component; `hud.ts` plus the `index.html` DOM become a React HUD. Estimate about 1,200 moved plus 300 new glue plus tests: size M, two Devin runs. The registry pattern is `ts/src/games/voiddrift_redux/config.ts:1-14`.
- Redundancy: `ts/src/games/voiddrift_redux/simulation/engine.ts` (1,218 lines) already has the same FSM (`engine.ts:361` `case 'Holding'`), cargo and unloading, plus Scout/Hauler drones and the Aluminum/H3Gas chain (`docs/demos/voiddrift_redux/SCOPE.md:2,4`). What the slice has that redux lacks is persistence (`docs/demos/voiddrift_redux/SCOPE.md:9`), which is a smaller job done in redux directly.

## Risks
- The VoidDrift roadmap names this renderer: `VD:docs/roadmap.md:24` reads "stop_if: The TypeScript rebuild in web/ replaces the Rust/Bevy game as the shipping line, or Robert pulls the game from sale." and `VD:docs/DIRECTION.md:74-76` says if it "becomes the primary line, it likely stops the Rust roadmap". The Rust game is the $4.99 itch.io release (`VD:docs/roadmap.md:10`). A studio port must be labelled a demo, never the shipping line, and that call is Robert's.
- Drift and duplication across two repos and a third near-copy (redux); no tests to catch drift.
- The lockfile resolves to `http://package-firewall.replit.local/...` (`VD:web/package-lock.json:17`), so `npm ci` fails off Replit; a port must not copy the lockfile.
