## 1. Why this exists

Roadmap M6.1 (approved 2026-09-22): graphics today use three technologies with no stated rule, and the plan in `2026-09-24-graphics-and-styles-plan.md` says `docs/GRAPHICS.md` is Phase 0, the document every later step (vector-to-sprite export, pixel style, rasteriser, sprite sheets) is allowed to cite. It does not exist yet (`docs/GRAPHICS.md`: no such file). Measured on main by Grep/Glob, the current split is: SVG for `ts/src/engine/artGen/`, the Paper Doll chimera renderer (`ts/src/engine/paperDoll/`), `ts/src/engine/shared/personGenerator/RoleSymbol.tsx`, `ts/src/games/slimeworld/components/SlimeVisual.tsx`, `ts/src/games/horse_racing/components/SVGRacer.tsx`, `ts/src/engine/shared/components/PlanetMap.tsx` (SVG plus DOM), and the Dissonance SVGs generated by `scripts/generate_dissonance_art.py` into `ts/public/assets/dissonance/`; Canvas 2D for `ts/src/games/shoal/components/ReefPreview.tsx` (and the shoal `App.tsx` canvas), `ts/src/games/slime_coin/components/BoardCanvas.tsx`, `ts/src/games/slither_rogue/components/GameCanvas.tsx`, `ts/src/games/voiddrift_redux/components/OrbitalCanvas.tsx`, `ts/src/games/mutant_battle_ball/components/MatchCanvas.tsx`, `ts/src/games/coin_pusher_arcade/components/BoardCanvas.tsx` and `ts/src/games/grainworks/hooks/useSimulationLoop.ts`; raster only the `ts/src/engine/creatureArt/fixtures/wolf.png` fixture. A short file with a test is cheaper than rediscovering this each time.
